<feature>
  <name>P&L Table, Amortization Table, and Dashboard Snapshot</name>
  <files>maple_return/analysis.py, tests/test_analysis.py</files>
  <behavior>
    All data structures use Decimal for monetary values. Functions are pure — no I/O, no side effects.

    **1. Amortization Table Row**
    - Dataclass `AmortizationRow` with fields: date, payment, principal, interest, balance
    - Signature: `build_amortization_table(schedule: list[AmortizationEntry]) -> list[AmortizationRow]`
    - Direct mapping from AmortizationEntry — thin wrapper for output consistency
    - All amounts in CAD

    Cases:
    - 360-month schedule → 360 rows
    - Empty schedule → empty list
    - Balance of final row is $0.00 (or near zero)

    **2. P&L Table Row**
    - Dataclass `PnLRow` with fields: year (int), gross_rent, vacancy_loss, net_rent, operating_expenses, noi, mortgage_payment, net_cashflow, principal_paid, interest_paid, equity_gained, cumulative_cashflow, cumulative_equity, cap_rate, cash_on_cash, is_partial_year (bool)
    - All monetary amounts in CAD
    - Signature: `build_pnl_table(annual_summaries: list[AnnualOperatingSummary], mortgage_annual_summaries: list[AnnualSummary], purchase_price: Decimal, current_property_value: Decimal, down_payment: Decimal) -> list[PnLRow]`
    - Cumulative cash flow: running sum of net_cashflow across all years
    - Cumulative equity: current_property_value - remaining_balance (uses mortgage annual summary year_end_balance)
    - Equity gained: year-over-year change in equity (current year equity - previous year equity); for year 1: equity - down_payment
    - Partial year detection: first year is always flagged is_partial_year=True (purchase year per user decision), last year flagged if < 12 months
    - Cap rate and cash-on-cash per row: computed via metrics module, annualized for partial years
    - Negative net_cashflow values are stored as negative Decimals (highlighting is UI concern, not data concern)

    Cases:
    - 5-year projection → 5 (or 6 if partial years at both ends) P&L rows
    - Cumulative cash flow grows over time for positive cash flow scenarios
    - Equity gained includes both mortgage principal paydown and property value appreciation
    - Year 1 (partial): is_partial_year=True, metrics annualized
    - Full year: is_partial_year=False, metrics use actual annual totals
    - Negative cash flow year: net_cashflow is negative Decimal, cash_on_cash is negative

    **3. Dashboard Snapshot**
    - Dataclass `DashboardSnapshot` with fields: as_of_date (date), equity_position (Decimal), equity_position_usd (Decimal), cumulative_cashflow (Decimal), cumulative_cashflow_usd (Decimal), annualized_return_irr (Decimal | None), current_cap_rate (Decimal), cash_on_cash_return (Decimal), months_held (int), current_property_value (Decimal), remaining_balance (Decimal)
    - Signature: `build_dashboard_snapshot(monthly_cashflows: list[MonthlyCashFlow], purchase_date: date, down_payment: Decimal, current_property_value: Decimal, remaining_balance: Decimal, cad_per_usd: Decimal) -> DashboardSnapshot`
    - "As of today": uses all cash flows from purchase date up to now (filter monthly_cashflows where month <= today)
    - IRR: computed via metrics.calculate_irr using filtered cash flows and current_property_value as terminal
    - Equity position: current_property_value - remaining_balance
    - Cumulative cash flow: sum of net_cashflow for all months up to today
    - Cap rate: based on most recent full year's NOI (or annualized partial year if no full year yet)
    - Cash-on-cash: based on most recent full year's net cash flow (or annualized) / down payment
    - USD equivalents for equity_position and cumulative_cashflow via convert_to_usd
    - months_held: count of months from purchase_date to today

    Cases:
    - 3 years held: dashboard shows 36 months, cumulative cash flow from 36 months, IRR over full period
    - 6 months held (partial year only): annualized cap rate and cash-on-cash, months_held=6
    - Negative cumulative cash flow: shows negative value, IRR may be negative or None
  </behavior>
  <implementation>
    Create `maple_return/analysis.py` with:

    1. Three dataclasses: `AmortizationRow`, `PnLRow`, `DashboardSnapshot`

    2. `build_amortization_table()`: Simple mapping from AmortizationEntry to AmortizationRow

    3. `build_pnl_table()`:
       - Iterate through annual_summaries and mortgage_annual_summaries together (matched by year)
       - Compute cumulative fields as running sums
       - Compute equity_gained as year-over-year delta
       - Flag first year and any year with < 12 months as is_partial_year
       - Call metrics.calculate_cap_rate and metrics.calculate_cash_on_cash for each row
       - For partial years, annualize NOI and cash flow before computing metrics: value = (total / months_in_year) * 12
       - Detect months_in_year: count of monthly cashflows in that calendar year (may need to accept this as a parameter or derive from the data)

    4. `build_dashboard_snapshot()`:
       - Filter monthly_cashflows to only those up to today
       - Sum net_cashflow for cumulative
       - Get remaining_balance from last filtered month or parameter
       - Compute IRR via metrics.calculate_irr
       - Get most recent year's NOI for cap rate (annualize if partial)
       - Compute cash-on-cash from most recent year's cash flow
       - Convert key values to USD via cashflow.convert_to_usd
       - Calculate months_held from purchase_date to today

    Imports: from metrics import calculate_irr, calculate_cap_rate, calculate_cash_on_cash, calculate_equity_position
    Imports: from cashflow import MonthlyCashFlow, AnnualOperatingSummary, convert_to_usd
    Imports: from mortgage import AmortizationEntry
    Imports: from mortgage_summary import AnnualSummary
  </implementation>
</feature>
