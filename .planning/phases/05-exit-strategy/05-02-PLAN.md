TDD RED-GREEN-REFACTOR for total return calculation. Extends the exit_model.py module created in plan 05-01.

**New Data Model:**

`TotalReturnSummary` dataclass:
- `hold_period_years: int` — same as sale_year from ExitInput
- `total_months: int` — number of months in truncated cash flow series
- `cumulative_net_cashflow: Decimal` — sum of all monthly net cash flows through sale year (CAD)
- `net_proceeds: Decimal` — from ExitResult (CAD)
- `total_profit: Decimal` — cumulative_net_cashflow + net_proceeds - down_payment (CAD)
- `total_profit_usd: Decimal` — USD conversion
- `simple_roi: Decimal` — total_profit / down_payment (quantized 4 decimal places)
- `hold_period_irr: Decimal | None` — annualized IRR using truncated flows + net proceeds as terminal value
- `exit_result: ExitResult` — full waterfall breakdown (nested, from plan 05-01)

**New Function:**

`calculate_total_return(exit_input: ExitInput, monthly_cashflows: list[MonthlyCashFlow], purchase_date: date) -> TotalReturnSummary`:

Logic:
1. Determine sale date: calculate end-of-year date for sale_year number of ownership
   - Sale year 5 means the last month of the 5th year from purchase_date
   - Use purchase_date to compute: if purchased 2020-06-15, year 5 ends at month 60 (2025-06-01)
   - Truncation: keep first `sale_year * 12` months of cash flows (or all if fewer available)
2. Calculate exit result: call calculate_exit(exit_input) for waterfall
3. Compute cumulative net cash flow: sum net_cashflow for all truncated months
4. Compute total profit: cumulative_net_cashflow + net_proceeds - down_payment
5. Convert total_profit to USD via convert_to_usd
6. Compute simple ROI: total_profit / down_payment (quantized to 4 decimal places)
   - Handle zero down_payment: return Decimal("0.0000")
7. Compute hold-period IRR: use existing calculate_irr from metrics.py
   - Pass: down_payment, truncated monthly_cashflows, net_proceeds (as terminal value instead of property value)
   - This replaces the operations-only IRR with exit-inclusive IRR
8. Return TotalReturnSummary with all fields

**Edge case handling (Claude's discretion):**
- sale_year beyond available cashflows: use all available months, log/handle gracefully
- sale_year = 0: return summary with zero months, no cashflows, IRR = None
- sale_price below mortgage balance: net_proceeds negative, total_profit negative, ROI negative
- zero down_payment: ROI = 0.0000
