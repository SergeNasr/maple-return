**Data Models (dataclasses with Decimal fields, consistent with existing models.py pattern):**

`ExitInput` dataclass:
- `sale_price: Decimal` — target selling price in CAD
- `sale_year: int` — year of ownership (e.g., 5 means end of year 5)
- `commission_rate: Decimal` — single commission % (e.g., 0.05 for 5%)
- `closing_costs: Decimal` — flat closing costs in CAD
- `remaining_mortgage_balance: Decimal` — balance at time of sale
- `purchase_price: Decimal` — original purchase price for appreciation calc
- `down_payment: Decimal` — initial investment for ROI context
- `cad_per_usd: Decimal` — FX rate for USD conversion

`ExitResult` dataclass (waterfall breakdown per user decision):
- `sale_price: Decimal` — CAD
- `commission: Decimal` — CAD (sale_price * commission_rate)
- `closing_costs: Decimal` — CAD (pass-through from input)
- `mortgage_payoff: Decimal` — CAD (remaining balance)
- `net_proceeds: Decimal` — CAD (sale_price - commission - closing_costs - mortgage_payoff)
- `net_proceeds_usd: Decimal` — USD conversion of net proceeds
- `sale_price_usd: Decimal` — USD conversion of sale price
- `implied_appreciation_rate: Decimal` — annualized appreciation (sale vs purchase price)

**Functions:**

`calculate_exit(exit_input: ExitInput) -> ExitResult`:
- Commission = sale_price * commission_rate, quantized to 2 decimal places
- Net proceeds = sale_price - commission - closing_costs - remaining_mortgage_balance
- Net proceeds can be negative (sale below mortgage + costs)
- Convert sale_price and net_proceeds to USD via convert_to_usd from cashflow module
- Calculate implied appreciation rate via calculate_appreciation_rate

`calculate_appreciation_rate(purchase_price: Decimal, sale_price: Decimal, years_held: int) -> Decimal`:
- Formula: (sale_price / purchase_price) ^ (1 / years_held) - 1
- Annualized compound appreciation rate
- Handle edge cases: years_held = 0 returns Decimal("0.0000"), purchase_price = 0 returns Decimal("0.0000")
- Quantized to 4 decimal places (consistent with metrics.py pattern)
