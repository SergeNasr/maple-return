**Functions to implement:**

`convert_to_usd(cad_amount: Decimal, cad_per_usd: Decimal) -> Decimal`
- Convert CAD to USD: `cad_amount / cad_per_usd`
- Quantize to 2 decimal places (ROUND_HALF_UP)
- Handle zero rate gracefully (return Decimal("0.00") if rate is zero)

`generate_monthly_cashflows(operating_input: OperatingInput, mortgage_schedule: list[AmortizationEntry], cad_per_usd: Decimal) -> list[MonthlyCashFlow]`
- For each month in the mortgage schedule:
  - Calculate operating data using `calculate_monthly_operating()` for that month's date
  - Pull mortgage data (payment, principal, interest) from the corresponding AmortizationEntry
  - Calculate net_cashflow = noi - mortgage_payment
  - Convert noi and net_cashflow to USD using convert_to_usd
  - Build MonthlyCashFlow entry
- Length matches mortgage schedule length (operating model runs for same period as mortgage)
- If mortgage schedule is shorter than expected (early payoff), operating schedule matches

`generate_annual_operating_summaries(monthly_cashflows: list[MonthlyCashFlow]) -> list[AnnualOperatingSummary]`
- Group by calendar year (same approach as mortgage_summary.py)
- Sum all monetary fields within each year
- Handle partial first/last years naturally
- Use itertools.groupby for efficiency
