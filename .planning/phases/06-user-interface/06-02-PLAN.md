  <action>
Create `maple_return/templates/wizard.html` extending `base.html`:

**Progress indicator** at top:
- 5 steps displayed horizontally using `.wizard-progress` CSS class
- Labels: "Property", "Mortgage", "Operating", "Scenarios", "Exit"
- Active step highlighted, completed steps show checkmark
- Steps are numbered 1-5

**Step container:**
- `<div id="wizard-steps">` contains all 5 step divs
- Each step is a `<div class="wizard-step" data-step="N">` (N=1-5)
- Only the active step is visible (others hidden via CSS/JS)
- Each step includes its partial template via Jinja2 `{% include %}`

**Navigation buttons:**
- "Back" button (hidden on step 1)
- "Next" button (steps 1-4)
- "Run Simulation" button (step 5 only, styled as primary)

**Client-side JavaScript** (inline in template, small footprint):
1. `currentStep` state variable, initialized from URL hash or 1
2. `showStep(n)` — hides all steps, shows step N, updates progress indicator, updates buttons
3. `validateStep(n)` — checks required fields in current step have values, validates format (numbers > 0, rates 0-1, dates valid). Returns true/false. On false: adds `.error` class to invalid inputs, shows `.error-message` spans.
4. `nextStep()` — calls validateStep(currentStep), if valid calls showStep(currentStep + 1)
5. `prevStep()` — calls showStep(currentStep - 1) (no validation on back)
6. `autoSave(field, value)` — HTMX-like fetch POST to `/api/save` with `{field: value}`. Called on input blur. Shows brief "Saved" indicator.
7. On page load: fetch `/api/load`, populate all fields with returned values, determine furthest completed step

**Auto-save on blur:**
- Each input has `onblur="autoSave(this.name, this.value)"` attribute
- Auto-save sends only the changed field to `/api/save`
- Visual feedback: brief green flash or "Saved" text near the field

**Form submit (step 5):**
- "Run Simulation" button calls `POST /api/simulate` via fetch
- On success (200): redirect to `/results` page
- On error (422): show error message with missing fields

Add route to `maple_return/routes.py`:
- `GET /wizard` — renders wizard.html template. This is the main entry point.
- Update the `GET /` route to redirect to `/wizard` (replace test page)
