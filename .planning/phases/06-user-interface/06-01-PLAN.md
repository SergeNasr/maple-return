  <action>
Create `maple_return/db_models.py` with a `PropertyConfig` SQLAlchemy ORM model that persists all wizard inputs as a single row (one property = one row). Use the existing `Base` from `maple_return/database.py`.

Table columns (all nullable except id, to support partial auto-save as user fills wizard):
- `id`: Integer, primary key, autoincrement
- `updated_at`: DateTime, default=utcnow, onupdate=utcnow
- Property step: `purchase_date` (String, ISO format), `purchase_price` (String for Decimal), `down_payment` (String)
- Mortgage step: `annual_rate` (String), `monthly_payment` (String), `amortization_years` (Integer), `rate_type` (String, "variable" or "fixed")
- Operating step: `monthly_rent` (String), `vacancy_rate` (String), `property_tax_annual` (String), `insurance_annual` (String), `maintenance_annual` (String), `management_fee_rate` (String), `rent_escalation_rate` (String), `expense_escalation_rate` (String), `cad_per_usd` (String)
- Scenarios step: `renewal_scenario_1` (Text, JSON string of [{rate, type},...]), `renewal_scenario_2` (Text), `renewal_scenario_3` (Text)
- Exit step: `sale_price` (String), `sale_year` (Integer), `commission_rate` (String), `closing_costs` (String)

Store monetary values as String (Decimal serialization). This avoids float precision issues.

Create `maple_return/routes.py` with a FastAPI `APIRouter` prefix="/api":

1. `POST /api/save` — Accepts JSON body with any subset of fields, upserts row id=1 (single property tool). Returns `{"status": "ok"}`. If row exists, update only provided fields. If not, create. This is the auto-save endpoint called by HTMX on each field blur.

2. `GET /api/load` — Returns full PropertyConfig row as JSON dict (all fields). Returns empty dict `{}` if no row exists. This loads wizard state on page load.

3. `POST /api/simulate` — Orchestration endpoint. Reads PropertyConfig from DB, validates all required fields are present, then:
   a. Build MortgageInput from config (purchase_price, down_payment, annual_rate, monthly_payment, amortization_years, start_date from purchase_date + 1 month, rate_type, renewal_scenarios parsed from JSON strings)
   b. Run calculate_multi_term to get scenarios
   c. For scenario[0] (base case): extract schedule, run generate_monthly_cashflows with OperatingInput
   d. Run generate_annual_operating_summaries, generate_annual_summaries, build_pnl_table, build_amortization_table
   e. Run build_dashboard_snapshot for current position
   f. If exit fields present: run calculate_exit and calculate_total_return
   g. Run compare_scenarios for scenario comparison
   h. Return JSON with all results serialized (convert Decimal to str, date to ISO string)

   On validation failure (missing required fields), return 422 with `{"error": "Missing fields: ..."}`.

   Helper: Create a `_serialize` function that recursively converts dataclass instances to dicts, Decimal to str, date to ISO string. Use `dataclasses.asdict()` as base and post-process.

Update `maple_return/main.py`:
- Import router from routes and register: `app.include_router(router)`
- Import PropertyConfig from db_models so it's included in Base.metadata.create_all

No new dependencies needed in pyproject.toml (FastAPI, SQLAlchemy, Jinja2 already present). Only update if needed.
